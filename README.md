# CyberShield - Manual de Defensa Digital y Ciberseguridad Básica

> **Documentación técnica profesional sobre fundamentos de ciberseguridad, instalación de herramientas de seguridad y pruebas de penetración éticas.**

## 📋 Descripción

CyberShield es una documentación completa creada con **MkDocs** y el tema **Material Design**. Proporciona una guía educativa exhaustiva sobre ciberseguridad, dirigida a estudiantes y profesionales de IT.

## 🎯 Contenido

El proyecto incluye **5 páginas principales**:

1. **Inicio** - Presentación e introducción al proyecto
2. **Introducción** - Conceptos fundamentales de ciberseguridad
3. **Instalación** - Guía paso a paso de herramientas necesarias
4. **Uso** - Herramientas prácticas y ejercicios hands-on
5. **Conclusiones** - Resumen y proyección profesional

## ✨ Características

- ✅ **Tema Material** con personalización personalizada (colores negro/cyan)
- ✅ **Extensiones Avanzadas:** admonition, pymdownx.details, pymdownx.superfences, pymdownx.highlight
- ✅ **Contenido Profesional:** 100% original y técnicamente correcto
- ✅ **Markdown Completo:** Títulos, listas, enlaces, imágenes, código, bloques desplegables, tablas
- ✅ **Navegación Intuitiva:** Menú superior tipo pestañas
- ✅ **Buscador Integrado:** Búsqueda de contenido
- ✅ **Responsive:** Compatible con dispositivos móviles

## 🚀 Instalación Local

### Requisitos Previos

- Python 3.7+
- Git
- Pip

### Pasos

```bash
# Clonar repositorio
git clone https://github.com/TU_USUARIO/Proyecto-Jose.git
cd Proyecto-Jose

# Instalar dependencias
pip install mkdocs mkdocs-material

# Servir localmente
mkdocs serve
```

Abre tu navegador en: **http://localhost:8000**
