## Buenas Prácticas a Mantener

### Seguridad Personal

```
✅ Usar contraseñas fuertes: Mín. 12 caracteres con mayúsculas, minúsculas, números y símbolos
✅ Autenticación de dos factores (2FA): Siempre que sea posible
✅ Actualizaciones periódicas: SO y software regularmente
✅ Copias de seguridad: Automated backups semanales
✅ Uso de VPN: En redes públicas siempre
```

### Ética Profesional

- 🛡️ Realizar pruebas **solo con autorización explícita**
- 🛡️ Respetar la **privacidad** de terceros
- 🛡️ Reportar vulnerabilidades responsablemente (Responsible Disclosure)
- 🛡️ Cumplir con legislación local (GDPR, CCPA, etc.)
- 🛡️ Mantener confidencialidad de datos sensibles
